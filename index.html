Introduction

What is the project about?

The Inventory Stock Alert System is a Java-based application designed to monitor stock levels of essential commodities (rice, wheat, sugar, kerosene) at public distribution shops. It gives shop staff and supervisors separate access, so shops are restocked on time and stock-outs become rarer.

Shop staff access

Update stock, view alerts, check history

Staff log in, record the stock issued or received each day, and see which commodities are running low.

Admin / supervisor access

Monitor shops, set thresholds, generate reports

Supervisors see every shop in one place, decide the alert thresholds, and review reports.

Problem statement

Why change the traditional approach?

Traditional stock monitoring relies on manual registers, delayed reporting, and reactive restocking.

  • Manual stock register maintenance at each shop
  • Delayed detection of shortages until beneficiaries are turned away
  • Errors in manual stock balance calculation
  • No real-time visibility for supervisors across shops
  • Time-consuming stock report preparation

A computerized stock alert system is needed to prevent shortages and ensure timely replenishment.

Proposed solution

A centralized stock monitoring platform

  • Shop staff can log in and update daily stock issued.
  • The system tracks remaining stock for each commodity in real time.
  • An automatic alert is generated when stock falls below the threshold.
  • Supervisors can view stock status across all distribution shops.
  • Stock records can be stored and retrieved for reporting.
Objectives

Project objectives

  1. Develop a user-friendly inventory stock alert system for distribution shops.
  2. Automate low-stock detection and alert generation.
  3. Maintain commodity-wise stock records for each shop.
  4. Calculate and update remaining stock accurately.
  5. Reduce shortages and manual monitoring effort.
  6. Implement Object-Oriented Programming concepts using Java.

    5. System checks threshold
    6. Alert generated if low
    7. Supervisor reviews alert
    8. Replenishment initiated
